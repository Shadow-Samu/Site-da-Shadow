# Shadow

Site da tripulação Shadow: inscrição, ranking de metas e títulos, chats por jogo, Central de validação e denúncias, conta com senha, chat privado por patente e painel admin.

O arquivo `index.html` é a página inteira. Ela usa o banco de dados e a identidade da plataforma Claude (Artifacts), então só funciona completa quando publicada como Artifact. Fora dela, o ranking e os chats não carregam e a inscrição cai no envio por e-mail.
